# OrxidStatBot V2

Telegram-бот статистики на Python 3.14 і aiogram 3. Працює через webhook
`https://orxid.in.ua/prod_orxmstat`; nginx передає запити на локальний порт 3004.

## Запуск

1. Скопіюйте `.env.example` у `.env` та вкажіть дійсний `BOT_TOKEN` і
   `ADMIN_IDS` через кому. Файл `.env` не зберігається в Git.
2. Створіть каталог `data` і дайте користувачу контейнера (UID 10001)
   права на запис: `mkdir -p data && chown 10001:10001 data`.
3. Якщо є стара база, **скопіюйте** `bd/botBD.db` у `data/botBD.db`
   перед першим запуском і дайте UID 10001 права на запис до копії.
4. Запустіть `docker compose up -d --build`.
5. Перевірте `docker compose ps`, `docker compose logs --tail=100 bot`
   та `curl http://127.0.0.1:3004/health`.

Контейнер перезапускається Docker після перезавантаження сервера. Нагадування
надсилаються самим ботом о 12:50 та 17:50, з понеділка по суботу, за
часовим поясом Europe/Kyiv. Окреме завдання cron не потрібне.

Для оновлення: `docker compose up -d --build`. Дані зберігаються в
`data/botBD.db` поза контейнером.

## Локальна панель

Після запуску відкрийте [http://192.168.1.10:3005](http://192.168.1.10:3005)
з пристрою в мережі `192.168.1.0/24`. Панель показує підсумки, щоденні
та річні графіки й останні витрати. Для неї працює окремий контейнер із
доступом до SQLite лише для читання. Він слухає тільки локальну адресу
сервера та відхиляє запити з інших IP. Токен Telegram у контейнер панелі
не передається.

У меню бота є кнопка «🌐 Веб-панель», яка надсилає локальне посилання.
За потреби адресу можна змінити через `DASHBOARD_URL` у файлі `.env`.
